IMPORTAÇÃO PREMIUM DO SITE RAIZ ANTIGO

Esta versão mantém tudo que foi criado no site novo: hero, calculadoras, Vida Delícia, Noivos, Delícia de Festa, História da Cida, Google Reviews, Localização e rodapé.

O bloco novo "Catálogo Premium Delícias da Cida" foi preparado para puxar o máximo possível do site antigo:
1. Mais Pedidos
2. Bolos Artesanais
3. Doces Gourmet
4. Confeitaria Inclusiva
5. Chocotones Especiais
6. Ovos de Páscoa
7. Galeria de Catálogos

Como funciona:
- O arquivo products.js tenta puxar produtos, fotos e descrições via WooCommerce Store API pública do site antigo.
- Se a API não carregar localmente, entra cache/fallback com produtos mais importantes já cadastrados.
- As imagens dos catálogos enviadas no chat foram adicionadas em assets/importados/catalogos.
- Onde tiver informação clara, o card mostra preço/descrição.
- Onde a informação estiver dentro da imagem, o site mostra como galeria premium e envia para WhatsApp.

Próxima etapa futura:
- Quando houver fotos novas, substituir imagens antigas item por item.
- Quando houver CSV/WooCommerce, refinar descrições e preços com 100% de precisão.
