# Delicias da Cida Premium V6

## Como visualizar
1. Extraia o ZIP.
2. Abra a pasta completa.
3. Clique em `index.html`.

Nao mova o `index.html` sozinho. Ele precisa ficar junto com `style.css`, `script.js`, `assets/`, `data/`, `integrations/` e `supabase/`.

## Como hospedar
Suba toda a pasta em Hostinger/cPanel/Netlify/Cloudflare Pages/Vercel.

## Integracoes preparadas
- Google Reviews: `integrations/google-reviews/`
- Catalogo antigo: `data/catalogo-bolos.json`, `data/catalogo-doces.json`
- IA/Supabase: `supabase/`
